# Каталог книжок посторінково + контакти учасників для дзвінків

## Що і навіщо

- **`listBooksPage(db, user, { page, limit })`** у новому модулі `src/books.js` —
  каталог книжок, відсортований за назвою, по сторінках. Фронтенд для читачів давно
  просив каталог, а віддавати всі книжки одним списком ми не хочемо. Сторінки
  нумеруються з 1, за замовчуванням 20 книжок на сторінку. Переглядати каталог може
  будь-який авторизований користувач.
- **`memberContacts(db, user, ids)`** у `src/members.js` — для бібліотекарів, які в
  понеділок обдзвонюють боржників зі `overdueReport`: раніше доводилося відкривати
  картку кожного учасника окремо, тепер можна отримати телефони й email одним
  викликом для списку id. Доступ — лише персонал (`requireRole(user, STAFF)`), як у
  `listMembers`.

## Тести

- Новий `test/books.test.js`: сторінка повертає правильну кількість книжок і лише
  поля `id`, `title`, `author`; без користувача — `AccessDenied`.
- `test/members.test.js`: тести на `memberContacts` для персоналу і відмову для
  звичайного учасника.
- Заодно стабілізував тест довідника учасників: він періодично падав у мене локально
  після змін у сид-даних, тож перевірку кількості рядків зробив менш крихкою.
