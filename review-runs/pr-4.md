## 3. Зауваження та дрібниці (Non-blocking / Nits)

### 1. [Edge Cases / Валідація] Відсутність перевірки формату вхідного рядка в `toUtcMs`
- **Файл**: `app/src/dates.js:7`
- **Цитата з коду**:
  ```javascript
  export function toUtcMs(iso) {
    return Date.UTC(Number(iso.slice(0, 4)), Number(iso.slice(5, 7)) - 1, Number(iso.slice(8, 10)));
  }
  ```
- **Зауваження**: Функція очікує валідний ISO-рядок довжиною щонайменше 10 символів. Якщо передати порожній рядок або невалідний формат, повернеться `NaN`. Оскільки це внутрішній хелпер модуля, це допустимо, але на майбутнє бажано додати базову валідацію або регулярний вираз `^\d{4}-\d{2}-\d{2}$`.

### 2. [Стиль імпорту/експорту] Дублювання зв'язування у `loans.js`
- **Файл**: `app/src/loans.js:2, 4`
- **Цитата з коду**:
  ```javascript
  import { addDays, daysBetween } from "./dates.js";

  export { addDays, daysBetween } from "./dates.js";
  ```
- **Зауваження**: Синтаксично Node.js дозволяє одночасний `import` і re-export `export ... from`, проте в деяких бандлерах це може викликати попередження про дублювання ідентифікатора.
